# Contribution

Welcome to Archer! We welcome your contribution.

## Before Your Contribution

Please read [Code of Conduct](./CODE_OF_CONDUCT.md) before your contribution.
The file contains important notices for your contributions.

## How to Contribute

### Check or Create Issues.

Please check the [Issues](https://github.com/Tayra-Sakurai/Archer/issues) before your addition of a new issue. If you have a new issue which does not exist in the page, please feel free to add a new one.

When you add an issue, please use the templates or forms if possible.

### Contribution Process

Please follow the following steps to contribute to our repository.

1. Please fork this repository.
2. Please make a new branch. The name of your branch is free.
3. Please make your edits.
4. Please test the repository in your local computer.
5. Please make the edit pass the all tests.
6. Please make your Pull Request.

The templates of Pull Requset are available.
Please make your message of your PR as clear as possible.
