# Security Policy

This explains the security policy of this repositoty.

## Security Update Support

This application is in development. So security update support is not available. However, until the stable version is published, the newsts version of this application includes up-to-date security batches.

## Reporting Vulnerability

Please report your findings on [designated Security Advisories Page](https://github.com/Tayra-Sakurai/Archer/security/advisories) when you find any vulnerability on this application.

**Never use the Issues Page** because this page is opened for also attackers.

Thank you for your cooperation for security update.
